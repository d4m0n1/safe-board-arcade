# Safe Board Arcade

Веб-версия карманной приставки в духе «Электроники» с двумя мини-играми и часами. Сделано как тестовое задание на стажировку Kaspersky Safe Board.

## Идея

Название стажировки обыграно буквально: Safe Board — это борт корабля. Медвежонок Kaspersky в капитанской фуражке собирает всех желающих к себе на борт, и корабль стажировок отправляется в плавание: обходит брёвна и собирает сокровища. Приставка и страница оформлены в тематике "Kaspersky: Safe Board".

На приставке три режима:

- **Игра А — Treasure Hunt.** Корабль идёт по морю с тремя линиями волн. Нужно переходить между линиями и двигаться вперёд-назад, чтобы собирать сундуки и не врезаться в брёвна. Сложность постепенно растёт.
- **Игра Б — All Aboard!** С причала разбегаются и прыгают в море люди, а медвежонок на кораблике должен поймать каждого. Со временем прыгают чаще и по нескольку человек сразу.
- **Время** — часы, этот экран открывается при запуске.

## Запуск

Нужен Node.js 20.19+ или 22.12+, этого требуют тесты (проверено на 20.20).

```bash
npm ci
npm run dev
```

Игра откроется на http://localhost:8080.

Другие команды:

```bash
npm run build   # сборка в dist
npm test        # юнит-тесты
```

В проекте есть `.npmrc` с `legacy-peer-deps=true`. Без него npm 10 падает при установке Vitest с ошибкой `Cannot read properties of null (reading 'edgesOut')` — это баг npm при разборе необязательных peer-зависимостей Vitest. Лок-файл собран в этом режиме, поэтому `npm ci` работает как обычно.

## Управление

| Кнопка приставки | Клавиша | Treasure Hunt | All Aboard! |
| ---------------- | ------- | ------------- | ----------- |
| Левая верхняя    | ↑       | линия выше    | вправо      |
| Левая нижняя     | ↓       | линия ниже    | влево       |
| Правая верхняя   | →       | вперёд        | вправо      |
| Правая нижняя    | ←       | назад         | влево       |

Режимы переключаются кнопками «игра А», «игра Б» и «время» или клавишами А / F, Б / , и В / D — буквы работают в любой раскладке. Кнопки на приставке нажимаются мышью или пальцем. Игра начинается и перезапускается любой игровой кнопкой. Звук выключается значком под приставкой.

## На что обратить внимание

- **Кнопки принадлежат приставке, а не играм.** Клавиатура, мышь и тач проходят через один модуль `src/controls.ts`. Игры только спрашивают, какая кнопка зажата, и не знают, откуда пришло нажатие.
- **В игры нельзя проиграть без шанса.** В All Aboard! точка падения каждого человека выбирается так, чтобы кораблик успел доехать до неё от предыдущей. В Treasure Hunt в ряду не бывает трёх брёвен, а расстояние между рядами всегда больше, чем нужно, чтобы объехать бревно на максимальной скорости. Это правило проверяет тест.
- **Сложность растёт до потолка.** Скорость, частота появления и количество объектов увеличиваются со временем, но у каждого параметра есть предел.
- **Всё настраивается в `src/config.ts`.** Координаты кнопок, размеры объектов, скорости и параметры сложности. Координаты в играх заданы в пикселях экрана 507×324, поэтому их удобно снимать прямо с макета.
- **Звук генерируется кодом** через Web Audio, отдельных аудиофайлов нет. Выбор «звук вкл/выкл» сохраняется.
- **Рекорды** хранятся в браузере отдельно для каждой игры. Если уйти на другой экран посреди игры, результат тоже засчитается.
- **Логика и отрисовка разделены.** Игра — это объект с `update` и `draw`, а общая оболочка `GameShell` отвечает за экраны старта и проигрыша, счёт, рекорд и игровой цикл. Поэтому логику можно тестировать без браузера.

## Структура

```
src/
  config.ts          координаты, скорости, сложность
  controls.ts        кнопки приставки
  sound.ts           звуки
  records.ts         рекорды
  games/             логика игр и отрисовка спрайтов
  components/
    Console/         корпус и кнопки
    GameShell/       старт, счёт, проигрыш, игровой цикл
    TimeScreen/      часы
    Decor/           украшения вокруг приставки
```
